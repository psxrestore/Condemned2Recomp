# Pull Requests / Contributions

**Condemned2Recomp** is in an early stage of development, and I'm prioritizing consistency, existing implementations, and established project requirements as the codebase evolves.

As a result, pull requests may be declined during this phase, particularly when they introduce changes that conflict with existing implementations, overlook project requirements, or add unnecessary complexity. Please note that if your PR hasn't been declined, I may still be considering it. Review times may vary!

I'm keeping contributions limited as I work towards v1.0. Contributions may be considered on a case-by-case basis. **Please consider opening an issue to discuss proposed changes before submitting a pull request!**

# AI/LLM Disclosure

Any pull requests created with the assistance of AI or LLMs must explicitly disclose that assistance.

- All submitted pull requests must be personally written and reviewed by the contributor.
- Contributors must understand and be able to explain their changes.
- Existing implementations, project conventions, and development requirements must be respected.
- Avoid unnecessary alternatives, refactoring, or additional complexity.
- All changes must be reviewed and tested before submission.

Pull requests that fail to meet these expectations may be declined.

Thanks for your interest in contributing to Condemned2Recomp!
